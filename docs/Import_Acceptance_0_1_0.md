# 0.1.0 导入状态修复候选验收

后续公共参数与右侧布局收尾见 `Shared_Parameters_Acceptance_0_1_0.md`；以下为本轮历史记录。

本轮基于本地 `be58e41a0d14a330583b77893a5748d0276abe8d`；保留既有候选包。
使用同一仓库和 `.venv`，不推送、不打标签、不发布。本轮只改导入生命周期、参数呈现
与验证脚本，不修改科学公式、原始输入、插件 API 或工程持久化格式。

## 用户路径与已确认原因

真实用户文件尚未提供有效本地路径。复现使用小型生成 TXT/XLSX，不能称为原文件验收。

- 已有实验来源，从顶部导入第二个来源：原代码先调用 New Project，清空原工程。
- 第二个来源误选实验：原代码重新解析所有来源并 AutoBind；两个同类候选变为歧义，
  原本明确的主通道选择丢失。现在追加保留原来源、校准、绑定和已完成计算。
- 同一表格解析器连续导入不同列序：原共享编辑器保留上一文件的映射。新条目现在有
  独立草稿，从空映射识别；只导入当前映射所属表格，其他待导入表格逐项确认。
- 删除来源时 Qt 临时选择信号与清空映射顺序交错；删除最后一项又留下旧解析器 ID。
  现在只在删除完成后恢复最终选择，空列表同时重置解析器和编辑器。
- 保存的时间列在预览返回前被空下拉框改成 None。现在保存索引和工作表名优先，
  非法索引明确交给解析器拒绝，不静默替换为首列。
- Probe/Preview/Parse 与待执行自动解析均核对会话、来源身份、类型、选择、偏移和配置。
  删除重加、切换来源、修改映射、新建工程或关闭后的旧结果不得写回当前状态。
- 两列 TXT 的 TR_F/TR_P/TR_T 歧义仍须明确选择。普通三列 TXT 使用已有 Generic Delimited，
  测试中显式选择它；XLSX 使用已有 Generic XLSX。没有添加专用解析器。

删除“来源计算参数”按钮与布局占位。选择“理论”后直接显示原有滚动参数区；实验/理论
计算、独立质量/区间/方向/修正、通道选择与指标保留。没有新增参数窗口或独立比较页。
