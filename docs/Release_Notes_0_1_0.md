# Underline RETLDC v0.1.0

火箭发动机试车记录的离线解析、校准、分析与导出工具。Windows 便携包完整解压后运行
`Underline_RETLDC.exe`，无需安装 Python。

本版主要变化：

- 实验和理论来源共用现有解析器及表格映射，旧工程默认实验来源；已有推力、室压、
  温度及适用数据浏览器时间图直接叠加理论曲线，支持选择、可见性和兼容单位换算。
- 共享理论显示平移、对齐当前实验与理论独立检测的试车起点、恢复原时序。显示调整
  不改变科学时间或原数组；视窗、来源和显示状态随工程保存恢复。
- 原结果区切换实验/理论指标，顶部统一计算；来源配置和结果独立，理论发动机物理
  参数来自实验工程模型。比冲仅使用有效推进剂质量，缺失时明确不可用。
- 全页同步的“仅分析工作区间”同时作用于时域显示和 FFT/既有变换输入，并可保存。
  FFT 恢复原有非等间隔线性插值，正确标注 Hz 和 `|rFFT|/N` 模值；长提示移到图下方。
- 顶部正式导出继续使用实验主流程。图表当前图导出可包含理论和显示变换；两条路径
  的数据含义在界面与文档中分别说明。
- 项目原创代码采用标准 Apache-2.0；保留第三方许可，提供匹配源码及 Qt/PySide、
  Mesa 原始归档、依赖版本和库重组证据。

验证：348 项 pytest、57 项针对性检查、源码及冻结 GUI 各 244 项、中英文启动和
仓库外解压启动通过；实际 TEST_SD 与合成参考的全段/工作区间 FFT 已逐点比对。
这些是软件与指定数据路径的检查，不构成传感器或现场硬件认证。Windows IME 人工
专项未运行，原生 C++ 库未重新编译。

FFT 使用 `abs(rFFT(y)/N)`，不是 PSD 或补乘 2 的单边幅值。有限但有时间空档的数据
沿用线性插值出图，频谱不能代表空档内实测信息；请检查提示并优先使用连续试车区间。
