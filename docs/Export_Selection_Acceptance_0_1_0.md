# 0.1.0 导出全选小项验收

基于 `1154849c4b821256d72a6af29f4d891b9f8ca78b`，仅修改统一导出窗口选择行为。
每次新打开窗口会勾选所有当前 enabled 格式，包括 metadata 默认不选的可用第三方格式。
“全选”按钮重复此动作；disabled 格式保持未勾选。窗口打开期间手动取消、可用性刷新、
语言切换及重复 show 不恢复取消项；关闭后重新打开按用户要求重新全选。空列表或全部
不可用时，全选与导出按钮均禁用。可用判定沿用现有能力/分析条件；ENG 元数据填写要求
保留。工程选择状态字段和插件 API 不变。

## 导出事实

| 类别 | 顶部统一导出 | 时间 |
| --- | --- | --- |
| 推力 CSV/ENG | 实验最终处理通道；无理论来源选择 | ACTIVE_TEST，点火为零 |
| 室压/温度 CSV | 实验 Primary 绑定所在 Dataset | 科学工程时间，全记录 |
| TXT/JSON 报告 | 实验主流程 analysis_result；不收集理论 source_analyses | 显示平移不参与；TXT 曲线表点火为零 |
| 正式推力 PNG | 仅实验最终处理曲线 | ACTIVE_TEST，点火为零 |
| 正式室压/温度 PNG | 仅实验绑定所在 Dataset | 室压裁剪 ACTIVE_TEST 且保留工程时间；温度全记录 |

统一导出入口为 `MainWindow._export_dialog_show` / `_export_execute`，输入解析由
`_export_input_resolve` 决定，右侧选择理论指标不改变这些输入。室压、温度输出使用
`MeasurementCsv_Write` / `MeasurementPng_Write`；最终推力使用 `ExportCurve_Extract`。
当前温度统一导出从首个 Primary 温度引用所在 Stream 取 Dataset，不聚合跨 Stream 来源。

图表的 pyqtgraph 右键 `Export...` 是独立入口：ImageExporter 渲染当前绘图，可包含理论
叠加、显示单位、平移、图例、参考线与当前范围；CSVExporter 输出添加到 PlotItem 的各条
曲线数组，包括理论显示坐标。其“original plot data”指绘图输入，不是文件原始时间；
默认每条曲线独立 (x,y) 列，不应用统一导出的试车截取。该入口本轮不改动。
只读检查时用零文件、无可见窗口夹具验证图表 CSV 两源/平移和图片理论可见性。

## 截图控件

父任务提供的 OCR 对应 `SourceAnalysisWidget` 当前保留的来源、通道、全记录/自定义区间，
以及复用的 Calculate 按钮；不是旧质量/阶段/方向/修正控件。未获取此次截图像素。
本轮不删这些唯一输入入口。后续最小布局方案可复用左侧通道与区间位置，右侧仅留指标
来源切换、计算和结果；模型仍分别保存科学时钟与各源配置，实验 Primary/分段不被理论覆盖。
