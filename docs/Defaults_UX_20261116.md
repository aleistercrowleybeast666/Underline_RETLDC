## 使用

在仓库运行 `.venv\Scripts\python.exe main.py`。

- 推力 → 推力修正 → **恢复默认修正：不启用**。只把修正草稿恢复为
  `AnalysisSession` 的新工程默认；保留原始数据、通道、方向、物理参数和试验区间。
  **恢复已应用值** 放弃草稿；**应用并重算** 才经原事务发布新结果。
- 工程 → 高级通道设置（通道与校准属性）→ **恢复模型参数默认值**。使用当前插件 schema 声明的
  标量默认值，保留当前模型、通道和单位。没有默认值、默认值为 null 或由其他对象
  提供的字段保持原值；没有可恢复参数时按钮禁用。取消保持工程不变。
- 工程 → 编辑工程发动机参数 → **恢复物理参数默认值**。`MotorPhysicalParameters` 的质量和
  尺寸缺省是“未提供”，不会填入 0 或估算值；型号、厂商和延迟保留。
  恢复只影响弹窗草稿，应用后相关分析待重算；取消、关闭后重新打开仍是已应用值。
  Enter 执行校验后的“应用”，不触发恢复默认；非法文本保留，Esc 继续取消。

校准的“应用”现在消费未按 Enter、未失焦的合法数字；非法或中间文本保留并定位，
不会静默回退后应用旧数。切换语言和主题只更新显示，不重建校准控件或清除导入来源。
恢复默认值、保存工程、重算和导出仍是不同动作。没有新增导航、科学公式、插件 API、
文件格式或全局清空功能。
