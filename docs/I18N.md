# Internationalization

Built-in locale IDs are `zh_CN` (简体中文) and `en_US` (English). JSON resources use stable dotted
keys such as `app.title`, `page.project`, `export.dialog_title`, and
`calibration.linear.name`. Built-in English and Chinese resources are test-enforced to have exactly
the same key set.

The Translation Service owns the active locale and emits `locale_changed` for runtime GUI updates.
The selection is stored in application settings and restored at startup. Business logic, combo-box
data, Plugin references, Calibration JSON, and Project JSON always use stable semantic IDs rather
than localized display strings.

Theme uses separate stable IDs `light` and `dark`. It is switched at runtime and persisted under
QSettings `ui/theme`; it is not a locale, translation key, Project field, scientific setting, or
formal-export input. Runtime locale switching preserves the numeric version `0.1.0`, retranslates
`By CXYL` / `辰星引力开发`, the `Light`/`Dark` ComboBox items, plugin display names, and schema
labels without changing the active theme or any stable plugin/configuration ID.

The `Project`, `Thrust`, `Chamber Pressure`, `Temperature`, and `Data Explorer` workspaces
and all Export/Plugin/Settings dialogs implement `retranslate()`. Runtime
switching refreshes their labels and schema-field labels without replacing stable ComboBox data or
discarding entered Parser/Calibration values. Schema properties may provide `x-i18n-key`; their
plain `title` is the fallback for third-party plugins.

Simplified Chinese translates the application-document meaning of `Project` as `工程`, including
navigation, New/Open/Save/Save As actions, defaults, diagnostics, and help text. `项目` is reserved
for an actual managed initiative. `Reset Chart` / `重置图表` is a localized page action; invoking it
changes only the interactive X/Y viewport and does not translate or rewrite segmentation IDs.

The product is the locale-independent `Underline RETLDC`; the window title is
`Underline RETLDC — 0.1.0`. Internal executable and repository names stay unchanged.
The Header composes stable `Underline` with only the localized
`火箭发动机试车数据解算` or `Rocket Engine Test Log Decoder and Calculator` suffix and never
shows the Project filename. Version labels are `版本 0.1.0` / `Version 0.1.0`; credit remains localized.
`语言` / `Language` and `主题` / `Theme` are bold Header labels, while their
ComboBox contents remain regular weight. Header and Settings theme ComboBoxes share the same
persisted `light`/`dark` value and remain synchronized across runtime locale changes. Their field
and popup text remains white on deep blue in both themes, independent of the translated item
width. The
formal full name is `Underline Rocket Engine Test Log Decode and Compute`. Chinese descriptive
copy uses `火箭发动机试车记录解析与计算软件` and `记录` rather than `日志`; English continues to use
`Log`. Quick Import category labels (`Time`, `Thrust`, `Chamber Pressure`,
`Temperature`, `Other`), Advanced Mapping, primary-binding controls, parser-ambiguity choices, and
shared workspace statistics all use paired resource keys. Their stored values remain stable IDs.

The Export dialog's first and default Output Language item is the stable `follow_ui` mode. It
resolves to the current UI locale whenever filenames and artifacts are generated, so a later UI
language switch updates `_ZH`/`_EN`, CSV/TXT/JSON labels, and PNG text. Explicit `zh_CN` and `en_US`
items remain available for output that must stay independent of the interface language.

`engineering` and `si_scientific` are stable Unit Display Mode IDs. Their labels, semantic axis
names, scientific-value formatting, Test Interval status, export group headings, and parser-radio
feedback are retranslated at runtime without changing Data Units or Project scientific state.

Scientific tokens remain stable and locale-neutral in persistence: Quantity IDs (`force`,
`pressure`), Unit symbols (`N`, `MPa`, `°C`), Unit Source IDs (`plugin_declared`, `default_si`,
`user_override`, `calibration_output`), semantic roles, and Calibration IDs are never translated
as stored values. The GUI localizes their labels and explanations, including the Identity warning
that “Already Calibrated” means no extra transform rather than sensor certification. Diagnostics
for unknown Units, nonphysical thrust metrics, and assumed baselines have matching zh/en keys.

The Export dialog has an independent output-language selector. Chinese artifacts use `_ZH` and
English artifacts use `_EN`; CSV headers, JSON display metadata, TXT report labels, and PNG-rendered
text follow that selection. `motor.eng` is intentionally excluded because its interchange format
is locale-neutral. Project files persist `follow_ui`, `zh_CN`, or `en_US` as a stable selection.

Plugin package scanning and installation use paired keys for discovery, manifest validation,
conflict checking, extraction, copy, Registry refresh, load verification, Application/User
locations, batch summary, Replace/Skip, and candidate status. Stable stage IDs such as
`CONFLICT_CHECK` and stable Plugin IDs remain untranslated diagnostic identifiers; their labels and
surrounding explanations are localized. The plugin preview contains no private progress control;
all translated task status is shown through the main-window global TaskManager/progress area.

Fallback order is:

```text
requested locale → en_US → supplied default → translation key
```

A missing file/key or formatting value does not crash the application. Every official and user
plugin may place `i18n/<locale>.json` beside `plugin.json`; bundles are discovered from the plugin
record's source directory and merged without requiring changes to application resources. Keys
should be namespaced by plugin ID. The bundled plugin zh/en key sets are test-enforced for parity.

`tabular.preset_auto_applied` displays the copied preset name in both locales and retranslates
with the current mapping summary. All analysis pages use the same Calculate Analysis Results
label. `Thrust Correction` / `推力修正` defaults to `None` / `不启用`.

Source origin choices use stable experimental/theoretical item data and paired `source.*` keys.
Overlay controls and legend prefixes use paired `theory.*` keys. Runtime language/theme changes
relabel view controls without changing origin, visibility, time alignment, or experimental results.

## Interactive plot tools

The desktop uses pyqtgraph 0.14.0 (supported dependency range `>=0.14,<0.15`). A scoped Qt
`QTranslator` bridges its existing ViewBox/PlotItem/Exporter/Form contexts to paired application
resources. Qt's unmodified `qtbase_zh_CN.qm` supplies standard Qt dialogs when available.
Unmatched text returns a null translation so Qt can continue its normal fallback; English mode
removes the Chinese Qt base catalog. Internal names, enum values, scientific tokens and numbers
are never translated. Runtime switching preserves pending axis range text, auto-range flags,
display transforms, selected export class, parameter values and Project plot view state.

`PlotUiLocalizer` refreshes the existing controls/actions in place. Its owned-scene ExportDialog
subclass handles upstream's hardcoded scene/plot labels and `Parameter.title`/list display labels;
list limits map translated labels to the original values. No upstream file, class or global
method is monkey patched. Unknown third-party text/configuration retains its original fallback.
The adapter retains Qt menu wrappers for its widget lifetime. UI labels and tooltips cover axis
links, mouse modes, transforms, downsampling, average, opacity, grids, points, export formats,
PNG/SVG/CSV/HDF5/print parameters and Boolean display labels. Native Windows chooser/print UI and
external applications may still follow their own language.

Current-plot CSV exports the arrays supplied to pyqtgraph: they already include the application's
Display Units and theoretical display shift, but not pyqtgraph's FFT/log/downsampling transforms.
It is distinct from the unified experimental CSV. Each-curve X/Y pairs retain separate sample
times. Shared-X mode joins Y columns by row using the first X; it does not time-align or resample.
Parameter names/values and the `_x`/`_y` header suffixes remain unchanged. A local CSVExporter
subclass resets 0.14's per-export column counter, preserving the X column on repeated shared-X
exports without changing arrays or calculation state.

SVG's format and options remain available and translated. On the tested Qt 6.11.1 runtime,
upstream's unadapted SVG coordinate parser already raises `ValueError` on simple plots; the
adapter preserves that behavior. PNG/CSV are exercised with real exported data. This work does
not rewrite the SVG renderer or claim its output issue is fixed. pyqtgraph's original MIT notice
is retained in `docs/third_party/pyqtgraph_LICENSE.txt`; Qt's bundled catalogs/licenses are unchanged.
