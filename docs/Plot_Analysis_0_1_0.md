# FFT 坐标与工作区间分析

图菜单的“变换”中有一个全页同步的“仅分析工作区间”开关，默认关闭。它复用已有
可手动调整的试车起止区间，不添加第二套选区，也不删除原始记录。状态保存于工程。

开启后，FFT、去均值及已有导数/相图变换先选取区间内的原采样点，再调用既有变换。
普通时间曲线也只展示工作区间，活动区间端点仍可拖动，已有起止时间输入可调整到
当前视图以外；关闭开关即可恢复全段并调整区间。PRE/POST 标记在裁剪显示时隐藏，
切换到 FFT 时隐藏全部时间区间及时域参考线，退出后恢复。自动范围使用当前裁剪/
变换后的数据，不把保存的秒坐标当成 Hz。

实验曲线使用 Project ACTIVE_TEST（兼容旧 `burn`）；理论曲线使用同一 Source 已有的
独立检测区间。理论未检测到区间时明确不可用，不借用实验区间，也不默认为全记录。
裁剪在 Stream 科学 Project 时间进行。理论显示平移与旧首点归零只影响显示，FFT
直接使用科学时间求采样间隔，不重复加减平移。端点仅选取已有点，不插值。

FFT 至少要求两个点、有限且严格递增的时间、有限数值、等间隔采样。沿用 pyqtgraph
0.14.0 的 0.1% 间隔容差；超出时提示不可计算，禁止其内置非等间隔插值分支。NaN
缺口不会被删去后拼接。其他既有派生变换保留原算法与缺口处理，不新增平滑或滤波。

## 实际 FFT 定义和单位

已检查项目安装的 pyqtgraph 0.14.0 `PlotDataItem._fourierTransform`：
`f = np.fft.rfft(y) / N`，显示 `abs(f)`，频率来自 `np.fft.rfftfreq(N, dt)`。
这不是功率谱或 PSD，也没有对非 DC/Nyquist 点乘 2，不能标为校准的单边振幅谱。
本次不改变该归一化算法，仅据实际计算标为“FFT 模值 |rFFT|/N”。例如整周期、幅值
6 N 的余弦在对应正频率处为 3 N；DC 保留均值，除非另外开启既有“去均值”。

横轴为频率/Hz；纵轴继承传入图项的显示单位（N/kN、Pa/MPa、K/°C 等）。温度等带
偏置单位的 DC 随显示零点改变，不能解释为绝对物理能量。工程/SI显示、对数轴及
中英文切换都保留这一单位语义；对数轴不再叠加手写科学计数标签或强制零刻度。

工程 `plot_views` 的 `fft_mode`、`subtract_mean_mode` 与每轴 `log_mode` 在恢复范围
之前恢复；旧工程缺失时默认关闭。`plot_analysis_active_only` 是独立的全局绘图偏好，
不作为校准、Processor、分段或分析完成状态。

## 导出与计算边界

当前图 PNG/SVG 显示当前变换及频率标签，允许显示理论曲线。图菜单 CSV 继续导出
完整的原图项输入数组（含显示单位与显示平移），不应用 FFT、去均值、导数、对数、
降采样或本次分析区间裁剪。界面提示已保留该区别，不把 CSV 冒充频谱数据。

已定义 ACTIVE_TEST 的总冲、Isp、压力/温度统计和来源独立计算继续由原计算流程决定，
不因本开关再次裁剪或重算。统一正式 CSV/报告/PNG 继续只用实验主流程及原导出规则，
不会因为当前图选了理论或 FFT 而改变输入。原始文件、Channel 数组、科学时间和
Project 分段均不变。相图算法与分析能力未扩展。
