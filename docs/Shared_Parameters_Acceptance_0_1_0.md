## 行为

- 工程设置中的药柱质量是唯一普通输入。新理论推力计算显式共用该值；显示单位继续
  使用已有公共设置。修改质量后，实验与共用理论推力结果变为待计算，分别重新计算。
- 右侧删除重复质量、计算输入阶段、方向、Processor、PRE/POST 和普通说明，只保留
  指标来源、必要的理论文件/通道/区间、计算按钮与结果。全记录时隐藏起止输入；
  自定义时显示。旧控件直接移除，布局随可见内容收缩。
- 新理论仍使用当前工程单位通道、+1、不启用修正，不套用实验分段或修正；显示平移
  不进入计算。公共质量变更不改原数组、处理通道、绑定、分段或其他测量族计算。
- 新配置保存 `mass_source=project` 和有效质量快照；旧配置缺失字段按 `source` 读取。
  显式旧质量、方向、处理阶段、修正及 PRE/POST 保持原值。加载存在差异的旧配置时
  给一次非阻塞状态栏说明。没有静默迁移；完成结果依原配置重算，草稿保持未计算。
- 质量缺失或非正时仅比冲不可用，其余可计算指标保留。计算任务执行期间改质量，
  旧任务结果不得写回。科学公式、插件 API v1、原始文件和采样点均未修改。
