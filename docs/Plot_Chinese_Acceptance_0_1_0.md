# 0.1.0 图表工具中文模式验收

用户已人工验收前一候选所有功能通过（`Sentinel_77b6f7ec4ba08191849323e151e8a4b7`）。
本轮只补图工具中文显示和必要的导出兼容处理。基线提交为
`b04bba94d9246ab2c9b45238699a6160cc5dd38e`；实际环境 pyqtgraph 0.14.0 / Qt 6.11.1。

利用上游 Qt 翻译上下文及原有 Qt 中文目录，不修改 site-packages。应用内实例适配器覆盖
右键菜单、X/Y 轴、鼠标模式、显示变换、降采样、平均、透明度、网格、数据点、导出对象树、
格式、参数及提示，随软件语言切换。保留控件/动作、未知第三方原文与内部字段/枚举值。
中文数字输入、轴范围、自动范围、参数选择、RGB/单位和科学数据保持独立。
标准 Qt 非原生窗口可用 Qt 译文；Windows 原生选择器、打印及外部软件仍可能使用自身语言。

CSV 的标题与列选项有中文解释；传入图项的数组已含显示单位和理论平移，但不含绘图库
FFT/对数/降采样。独立 X/Y 保留不同采样时间；共享 X 仅按行拼接，不时间对齐或重采样。
局部 CSV 子类修复 0.14 重复共享-X 导出丢失 X 列的问题，保留原字段和值。
PNG 继续包含当前绘图、理论叠加和显示变换。正式实验导出不变。

保留 SVG 格式与中文参数。当前 Qt 6.11.1 中，原版 pyqtgraph SVG 坐标解析在简单图表上
已抛出 ValueError，适配器保持相同行为；本轮未修复其渲染器，不能宣称 SVG 输出通过。
依赖限定 `pyqtgraph>=0.14,<0.15`，防止未经验证的控件结构升级。
上游 MIT 许可原文保存在 `docs/third_party/pyqtgraph_LICENSE.txt`；Qt 目录与许可不变。
