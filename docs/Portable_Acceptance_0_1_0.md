## 用户最短验收路径

1. 将整个便携 ZIP 解压到可写目录，运行其中 `Underline_RETLDC.exe`；无需 Python。
2. 为 `结果.xlsx` 新建独立工程，核对自动识别的时间、F 和 Pc 单位及 Other 列。
   在四个时间曲线页面检查相应曲线；来源计算不填写未经确认的推进剂质量。
3. 将明确标注的合成参考以理论来源导入相应独立工程，检查虚线图例、可见性和单位。
   不将两份独立实验默认混成一个试验，也不把合成参考称为实际理论结果。
4. 在原结果区切换指标来源并计算；正负平移、归零及恢复后核对实验指标未变。
   保存/重开，再仅删除理论来源并保存/重开，核对实验曲线、绑定及结果仍在。
5. `TEST_SD.TXT` 可先预览并检查高级映射；时间基准、测量单位及需要的校准明确后再计算。
   未确认时停留在预览/待配置状态，不用默认 1 Hz、N 或推测的质量完成验收。
