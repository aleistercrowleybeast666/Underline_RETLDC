## 复核发现与修复

- 初次实现按路径去重，遗漏“同一文件两种来源”。现在按路径＋来源类型去重，列表每项保存
  独立来源、Source ID、偏移和解析状态，精确选择/删除；不会同时删掉同路径的另一种来源。
- 同路径重开不能重用另一来源的 Dataset。现在根据稳定 Source ID 识别主解析 Dataset，
  其余来源各自执行保存的解析器/映射；同文件可使用不同列映射及单位，引用与 SHA 可相同。
- 快速重复点击曾可能覆盖已完成但尚未交付的回调。任务仍持有回调时不接受替换；重复解析
  会先交付已完成回调，再检查实际待导入项。没有额外并行导入或主线程等待弹窗。
- 修改主要推力输入时同步工程来源/校准视图，避免界面仍指理论来源而 active Stream 已改变。
- 仅理论室压视图的压力参考线/输入值跟随实际理论目标 Display Unit，并在切换目标或 SI 模式
  时刷新；Pa、kPa、MPa 参考值使用现有 Unit Registry，原始压力与计算没有改变。

## 明早最短验收路径

1. 复用现有环境启动：`.venv\Scripts\python.exe main.py`，打开已有实验工程，记录当前主通道、
   试车区间、自重补偿选项和关键指标。没有工程可导入带 Time(s)、F(N)、Pc(Pa)、Temperature(K)
   列的小 CSV；普通文件仍使用已有解析器/映射。
2. 工程页把“新增数据来源”选为“理论数据”，添加理论文件（也可再次添加同一文件），确认
   实验/理论两个来源标记，完成解析及工程单位核对。
3. 依次查看推力、燃烧室压力、温度、数据浏览器；核对理论虚线/图例、可见性和单位换算。
   数据浏览器选择要对照的相同物理量，Other 可启用“显示辅助通道”；错误单位应显示不可用原因。
4. 对理论来源试正负平移、首有效时刻归零及恢复原时序；核对实验主通道、区间、自重补偿和
   指标不变。归零不是点火检测或自动拟合。
5. 保存、重开，确认理论显示状态恢复；只移除理论来源再保存、重开，确认实验结果仍在。
