理论和实验推力计算均接收由实验工程设置解析的 `MotorPhysicalParameters`：推进剂质量、
发动机总质量、直径和长度，缺失值为 None。Isp 仍只使用推进剂质量；现有公式不使用总质量
及尺寸产生额外指标，它们作为共同输入和结果来源记录。物理参数编辑使相关推力结果待计算，
保留通道、校准、分段、修正和各来源区间。旧理论冲突值留在 `legacy_physical_parameters`；
实验值（含缺失）优先，完成结果按有效参数重算，草稿不自动推进。载入有非阻塞说明。

原精简结果区、唯一工具栏计算动作、正式导出实验来源、右键当前图导出及导出全选行为保留。
不增加公式、插件 API 代际或工程格式代际；工程 `/2` 以可选字段扩展。
