# 0.1.0 图轴视窗与共享发动机参数验收

本轮基于 CompactResults 提交 `3be204ecd7300531ee99d199e1d241c9eccce1a6`。
工程新增可选 `plot_views`，按稳定页面/图轴 ID 保存显示范围及自动范围开关/比例。
共享 ViewBox 图轴只保存一次；关联图轴引用目标，多图轴保留各自 Y 范围。
数据、曲线、理论平移和初始化刷新完成后恢复视窗；延迟恢复使用 Session 身份保护。
切页保留缩放，不重复平移，不改变原数组、科学时间、区间或正式导出。
缺少字段的旧工程先重置到数据驱动的默认视图，不继承同一窗口上一工程的缩放；随后才
恢复当前工程已保存的图轴。非法范围、非有限值和非法自动范围值被拒绝。

理论和实验推力计算均接收由实验工程设置解析的 `MotorPhysicalParameters`：推进剂质量、
发动机总质量、直径和长度，缺失值为 None。Isp 仍只使用推进剂质量；现有公式不使用总质量
及尺寸产生额外指标，它们作为共同输入和结果来源记录。物理参数编辑使相关推力结果待计算，
保留通道、校准、分段、修正和各来源区间。旧理论冲突值留在 `legacy_physical_parameters`；
实验值（含缺失）优先，完成结果按有效参数重算，草稿不自动推进。载入有非阻塞说明。

原精简结果区、唯一工具栏计算动作、正式导出实验来源、右键当前图导出及导出全选行为保留。
不增加公式、插件 API 代际或工程格式代际；工程 `/2` 以可选字段扩展。
