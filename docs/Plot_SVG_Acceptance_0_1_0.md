# 0.1.0 SVG 兼容性收尾

修复 Qt 6.11.1 / pyqtgraph 0.14.0 的合法闭合命令 `Z` 被当作坐标对读取而失败的问题。
原版相同样本仍能复现 `ValueError`；应用的同一 SVG 菜单改用 `PlotSVGExporter`。
继承原版参数，在应用内保留上游逐项重建、裁剪、变换、字体和线宽辅助代码，仅让
无坐标的 `Z`/`z` 原样通过。未改第三方安装文件或全局函数，未删高级功能或中文模式。
MIT 原文保留于模块及 `docs/third_party/pyqtgraph_LICENSE.txt`。

Qt SVG 查看器不支持 `clipPath`，所以“能加载”不能证明裁剪有效。自动回归分别检查
裁剪几何、被裁剪曲线层级和视窗内栅格位置，并用独立 Chromium 画布核验真实裁剪。
实验/理论同图、原采样点、NaN 缺口、数据数组、科学计算与保存视窗保持原语义。
右键导出为当前图路径，可含理论叠加；正式统一导出仍用实验主流程。
