## 本轮行为

- 推力、燃烧室压力、温度及数据浏览器共用一个理论显示偏移。滑条与数值输入双向同步。
- 实验与理论分别检测区间，只绘制实验区间。对齐使用当前实验起点（包括人工编辑）减去
  理论原始科学时间中的起点；重复点击不累计，对齐后仍可拖动微调。
- 理论检测缓存保存完整通道引用与原始区间。校准、重解析、检测通道/方向变化使缓存失效。
- 原有指标来源只显示“实验 / 理论”。多个理论文件在折叠参数内选择，各自参数和计算结果
  仍独立；未删减原有映射通道或指标。缺少质量时比冲保持不可用。
- 偏移、可见性及理论检测不更改原文件、原始时间、科学积分或实验结果。

## 生命周期故障与证据边界

保留的 `focused-final.log` 记录 `0xc0000374` 原生堆异常；其 XLSX/GC 堆栈是发现位置，
不足以单独证明根因。带销毁线程记录的复测也发生相同异常，发现前一测试失败后 worker
仍存活，下一个窗口已开始构造。被监控的曲线对象未记录到跨线程销毁；不能据此排除其他
Qt/Python 引用环或底层运行时问题。

确定性回归在修复前失败：运行中的任务尚未退出，窗口关闭就已经被接受。现在关闭会先
取消任务和待执行自动导入，保持事件循环响应，待 worker 退出后再销毁；不交付关闭后的
GUI 回调。自动导入、导入布局和分析布局改用所属对象持有的定时器。

测试清理先等待 worker 取消退出，再销毁窗口，最后在主线程回收遗留的 Python 引用环。
没有禁用全局 GC、跳过测试或捕获原生异常假装通过。一次定向完整复测已经通过，但
不能把它等同于原生堆异常根因已被完全证明；最终重复验证结果见下方。
修复后的定向序列、两轮全量进程（首轮仅布局断言失败）及三次独立桌面运行均未再次出现
该原生崩溃。仍缺少指向具体原生指令的根因证明，因此本包保留稳定性观察风险；用户真实
数据验收和后续持续使用仍有必要，不能将一次通过或测试环境清理等同于彻底消除底层风险。
