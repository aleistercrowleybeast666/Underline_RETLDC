## 生命周期与线程审查

可复现问题：删除图主人后，导出 QWidget 仍存活，所引用 Scene 的 C++ 对象已销毁。
修复为独立窗口设置对应图 QWidget 的 Qt 父对象；窗口显示方式保持独立，主人删除时
窗口一并销毁。3 次创建/销毁回归检查 C++ 有效性和 locale 连接数，不留旧窗口连接。
这是真实生命周期缺陷，但不能证明它造成首次启动访问冲突。

Qt 翻译器由 QApplication 上的实例持有；绑定同一 TranslationService 不重复连接，
换服务先断开旧服务。所有绑定/更新明确限制在 GUI 线程。菜单包装器有图实例强引用；
Boolean 参数连接用弱集合去重。没有系统进程枚举、后台 UI 修改或全局第三方猴补丁。

仅对 smoke 命令启用 `UNDERLINE_NATIVE_DIAGNOSTICS_DIR` 环境开关：写原生 faulthandler
栈文件及逐阶段 JSONL（Qt 初始化、窗口构造/显示、语言切换、真实右键菜单、CSV/PNG、
事件循环退出与关闭）。诊断运行使用自己的 settings.ini；普通运行不启用此诊断。
有界启动各运行两次语言切换，不作大循环或长期占用 GUI。

## SVG 定位与支持范围

同一 pyqtgraph 0.14.0 / Qt 6.11.1、相同样本和窗口尺寸下，原版与适配版均失败于
`SVGExporter.py:427` 的 `x,y = c.split(',')`。失败路径为：
`M0,0 L863.5,0 L863.5,528.5 L0,528.5 L0,0 Z`，失败 token 是闭合命令 `Z`。
不是译文、字段 ID 或数值变化导致。

也探查了公开 Qt SVG 生成器：生成文件可加载，但没有 clipPath，缩放视窗下与 PNG
渲染不一致。因此不能用它作保留视窗裁剪的安全替代。修复上游私有坐标解析器需要维护
完整路径/变换逻辑或不安全替换模块全局函数，本轮不采用。保留 SVG 菜单与参数，不静默
禁用；本环境 SVG 输出仍不支持。PNG/CSV 继续实测，不改变原数据、列语义或理论显示变换。
