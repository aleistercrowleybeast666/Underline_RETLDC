Underline RETLDC — third-party software notices
==============================================

Original UNDERLINE project code is licensed under Apache License 2.0; see the root
LICENSE and the scope statement in README.txt. No personal copyright line has
been added. The standard appendix example is not a project copyright assertion.
This notice preserves third-party terms: the project license does not relicense
Qt/PySide, pyqtgraph-derived code or other dependencies.

The Windows portable application includes Python, NumPy, SciPy, pyqtgraph,
PySide6/Qt and Shiboken. Their copyright notices and exact license documents are
retained under docs/third_party/. During packaging, scripts/collect_licenses.py
copies the installed distributions' documents and records versions and SHA-256
hashes in docs/third_party/runtime/manifest.json.

- Python: Python Software Foundation and other included notices; see runtime/Python.
- NumPy and SciPy: BSD terms plus their bundled component notices (including
  OpenBLAS, LAPACK and GCC runtime exceptions). Read the complete upstream files;
  the presence of GPL text in those files is not an UNDERLINE licensing decision.
- pyqtgraph: MIT; docs/third_party/pyqtgraph_LICENSE.txt. The local SVG adapter is
  derived from pyqtgraph 0.14.0 and retains the upstream copyright/license.
- pyqtgraph CET color maps: the upstream CC-BY document is copied separately.
- PySide6/Qt/Shiboken: the installed distributions advertise alternative LGPL/GPL
  terms and a commercial option. License texts in upstream/ are reference copies,
  not proof of a commercial entitlement or selection of a project license.
- Qt Virtual Keyboard: the original PlotSVG candidate includes this module and
  its input-method plugin. Its published options are GPLv3 or commercial. New
  build outputs exclude these unused optional files; the original is preserved.
  The module must not be described as covered by LGPL alone.
- OpenSSL: the observed candidate includes versions 3.0.18 and 3.6.4; both exact
  upstream LICENSE texts are retained. This does not establish that all nested
  notices or supplier build details have been verified.
- PyInstaller: build/bootloader notices are included for reference. Its bootloader
  exception does not choose an application license or replace dependency duties.
- The frozen archive also contains pytest, pluggy, iniconfig, colorama, packaging,
  Pygments and setuptools (including vendored components). Their notices are
  collected even though they are not scientific workflow dependencies.

New outputs also exclude the unused PDF image reader/library and orphan QML/Quick
closure (seven further files). Image writer formats are unchanged. Eight Qt DLLs
remain; the original PlotSVG package is preserved.

The separate filtered validation directory demonstrates the exclusion rule. It
does not license UNDERLINE or remove LGPL duties from the remaining Qt libraries.

The complete corresponding-source/installation-information route for Qt, nested
Qt/image-format/software-OpenGL attributions, and Windows runtime redistribution terms still
need release review. License text collection is not a declaration of compliance.
